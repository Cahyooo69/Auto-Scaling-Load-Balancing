Pusat Bantuan Cepat (FAQ)

Pertanyaan umum seputar alur war tiket dan pencetakan E-Ticket.

Mengapa saya diminta login sebelum memilih kursi?

Untuk menjaga keadilan antrean war tiket serta memastikan identitas penonton tercetak valid di Order ID & E-Ticket Resmi.

Apakah dua orang bisa mendapatkan nomor kursi yang sama?

Tidak. Sistem menggunakan skrip atomic Redis Lua serta transaksi ACID PostgreSQL sehingga kursi yang sudah dikunci langsung tertutup bagi pengguna lain.

Bagaimana cara membeli beberapa konser sekaligus?

Di halaman Konser, centang tombol Pilih pada beberapa kartu konser lalu klik War Terpilih Sekarang di bilah bawah.

Bagaimana hasil cetak E-Ticket PDF terlihat?

Klik Cetak / PDF setelah pembayaran sukses. Navigasi, tombol, dan ID worker server otomatis disembunyikan agar tercetak bersih dalam 1 halaman A4.
